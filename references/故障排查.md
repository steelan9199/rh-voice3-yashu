# 参数全表与故障排查

`node scripts/rhv.mjs help` 是参数的主副本，这里补它没写清的语义。

## 一、参数全表

| flag | 模式 | 说明 |
|---|---|---|
| `--text` / `--text-file` | design/clone/director | 要念的台词；长句、带引号、带换行的写进 txt 更稳（stt 不需要）。**两个同时给时 `--text` 赢**（实测：`--text "文字参数优先"` + 401 字 txt → 用的是 6 字那句），改稿后忘了删旧的会静默用错 |
| `--voice` / `--voice-file` | design | 音色描述，**自然语言四层写法**，不给音色 ID。**文化强标签**（霸总 / 播音腔 / 客服 / 纪录片旁白 / 电台深夜档…）只能定方向、**绝不能单独用**——同标签换种子会漂；正确写法是标签打头 + 四层补齐（「霸总音，三十二岁男声，尾音往下压」）。脚本对强标签不报「太短」，只出一条 info。横评证据见 `声线库.md` §六 |
| `--ref` | clone/director/stt | 参考音频。10–20s、干净、单人、无配乐、**不循环**。时长口径见 `模式详解.md` §一 |
| `--ref-text` / `--ref-text-file` | clone/director | **参考文稿**：参考音频里逐字说的话（含重复、语气词）。给了就走「带参考文稿」那条图、跳过 Whisper；不给就用内置转写 |
| `--direction` / `--direction-file` | director | 导演指令，**写密**才改得动 |
| `--instruction` | clone | 高级：节点 `#56` 的 instruction，默认空，一般不用碰 |
| `--out` / `--name` | 全 | 产物目录（默认 `./voice-out`）、文件名前缀（默认模式名） |
| `--cfg` | clone/director | clone 默认 1（照抄参考），往上调到 1.2–1.5 ≈ 偷一点语气变化（**未实测**）；director 默认 4。`infer.py` 另有 `guidance_scale_ref` / `guidance_scale_ins` 两个独立口子，走单 cfg 时三者同值 |
| `--trim [秒]` | clone/director | 参考音频超 20s 时先截到 20s（需 ffmpeg），**上传的是裁剪后的副本**。超 60s 且没给 `--trim`：脚本退出码 2、不发请求、不扣币；给了 `--trim` 则先裁再判，裁完仍超才拒——60s 是节点层硬上限（README `hard max 60 s`），理由见 `模式详解.md` §一 |
| `--mp3` | 全 | 本机有 ffmpeg 就顺手转 mp3，flac 保留 |
| `--seed` | 全 | 一个随机数（`#3` 的普通采样参数，与 temperature / top_p 同级）。不控制音色、语速、停顿；换它只是换一条采样路径，结果大体相同、细节随机。同 seed 也不保证复现（两次独立提交的实测见 `实测数据.md` §五） |
| `--timeout <秒>` | 云模式 | 轮询上限，默认 600 |
| `--poll <毫秒>` | 云模式 | 轮询间隔，默认 1500、下限 500。只有排查「卡在排队还是卡在跑」时才调，别调成秒级去刷 |
| `--json` | 全 | 结果以 JSON 打印 |
| `--dry-run` | 全 | 只打印请求体，不提交、不花钱 |
| `--cast` | dialogue4 | 角色表 + 剧本的 json 路径 |
| `--no-preflight` | dialogue4 | 跳过提交前的图预检（只在确认平台侧问题、非要硬跑时用） |
| `--in` / `--preset` / `--mix` | fx | 干声输入 / 预设名（中英文都认）/ 湿度覆盖 0–1 |
| `--target` / `--tp` / `--suffix` / `--out` | lufs | 目标 LUFS（不给按声道自动）/ 真峰值上限默认 -0.5 / 输出后缀默认 `_std`（源文件不动）/ 输出目录 |

## 二、退出码

**2** 参数问题 / **3** 没有可用密钥 / **4** 跑起来但失败。

密钥解析顺序：技能根目录 `RUNNINGHUB_API_KEY` 文件（空文件或内容不像密钥时自动跳过）→ 环境变量 `RUNNINGHUB_API_KEY`；都不合格才退出码 3，**不发请求、不扣币**。每次运行都打印一行「密钥来源」，换 key 排错先看它。

## 三、`dialogue4` 的自动转写是坏的——ref_text 必须自己给

**范围只说一遍：这条只对多角色那张图成立。** 单角色 clone/director 的自动转写实测正常，给了稿没给稿都出音频（数字见 `实测数据.md` §八）。别照着这条去拦单角色。

`auto_transcribe_if_empty=true` 在多角色 Speaker 节点上必崩：

```
ValueError: The generation config is outdated and is thus not compatible with
the `task` argument to generate.  (whisper.py → transformers generation_whisper.py)
```

任务 FAILED 但 **照扣费**，且报错只回一句「工作流运行失败」，`errorMessage` 是空的——真原因藏在 `/query` 返回的 `failedReason.traceback` 里。图上的四槽已于 2026-10-30 手动改成 `false`，脚本另外恒推 `false` 兜底。

**有 ref 却漏了 `ref_text` 时，脚本在提交前就拦（上传和读图都还没做，一分不花）**，并把该转的命令逐条打出来——它不会替你自动转，而是明确指向本技能的 `stt` 模式：

```
有 4 个角色给了参考音频，但没给 ref_text 逐字稿：韩立、南宫婉、银月、紫灵
  ...
  所以逐字稿得自己给。用本技能自带的 stt 模式（Whisper 语音转文字）先转一遍：

    node scripts/rhv.mjs stt --ref "…/01_韩立_凡人修仙传.mp3" --name "韩立" --out ./stt-out
```

看到这段提示，**下一步是去跑那几条 `stt`，不是绕开它**——`--dry-run` 下这条拦截同样生效（故意的），`--no-preflight` 也绕不过。缺一个角色的逐字稿，整张图都跑不起来。

## 四、故障对照表

| 症状 | 处置 |
|---|---|
| `E_SUBMIT … not exist` / 无权限 | ① 密钥不是这个账号的 → 去「个人中心 → API 控制台」重抄；② 这条工作流没在该账号网页上跑通过（RH 硬规定）→ 网页点一次运行、出过音频再重跑 |
| `E_SUBMIT 421` | 并发已满。脚本按 10s / 20s / 30s 退避重试三次；**别自己并发提交**（账号额度就是 1 条，见 `SKILL.md` 红线 1） |
| `E_FAILED` | 看返回里 errorMessage；重试必然同样崩，别盲目重跑 |
| `E_FAILED 工作流运行失败`（`errorMessage` 空） | 平台把真原因藏在 `failedReason.traceback`：拿 `/query` 的返回看 `node_name` + `exception_message`。已知两条：`BreezeTTS2Speaker` 的 auto-transcribe 崩（见上节）、Speaker 重名/无音频无指令 |
| `E_NO_OUTPUT` | 输出节点不被平台识别 → 回网页把 AUDIO 接到 `PreviewAudio` / `SaveAudio` 再保存 |
| `E_TIMEOUT` | **先别重跑**（可能已生成只是没取回），去网页看任务记录，确认没有再加 `--timeout 900` |
| 克隆出来不像 / 像但不像 | 参考音频不干净或太长；换 10–20s 单人干声。仍不像就改走 director + 写密指令 |
| 导演指令像没生效 | 指令太笼统。补齐语速/音量/情绪/气息/口音/停顿六个维度，一次只改一项对照；用字/秒反查 |
| 台词念到一半语调飘、后半段散 | **单段超 150 字**——这是听感线，音频是完整的，但后半段语调开始飘。拆成几条分别跑；每条独立扣费，先说清要拆几条。**别把这条当成截断**（吞尾的线低得多，见下一行） |
| **产物时长正常、结尾却少了一段**（最常见也最坑） | **不是坏了，是被静默截断**：退出码 0、文件照出、时长照常。**看电平靠不住**——末尾安静也可能是丢了整段。唯一可靠的是按 `实测数据.md` §四那条规范命令截末段后转写，**逐字**跟原文比。稳妥线与各次实测点见 `实测数据.md` §九，对策只有拆条 |
| 克隆「像但咬字别扭」 | 先排除转写错字：跑 `stt` 对一遍参考文稿，再 `--ref-text` 喂回去 |
| `stt` 报 `E_NO_OUTPUT …没返回 txt` | `#65 SaveText` 不在图上 / `format` 被改了 → 回网页把 `#60` 接到 `SaveText(format=txt)` 再保存 |
| `stt` 转出来尾部缺几轮 | 不是产物被截断，是 whisper 只吃 ~30s 窗口。按 `实测数据.md` §四那条规范命令截末段再转 |
| `ECONNRESET`（只失败 1–2 次就过） | 正常网络抖动，脚本退避重试后继续，**什么都不用做** |
| `ECONNRESET`（四轮全灭） | **不是网络抖动**：本机 Node 的 fetch 不读代理环境变量，命令前漏了 `NODE_USE_ENV_PROXY=1`。加上再跑，别去查网络、别重试同一条 |
