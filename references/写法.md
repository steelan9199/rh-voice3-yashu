# 声音怎么描述、指令怎么写

只在**写描述 / 写指令卡住**时读这份。只想跑一条音频的话，回 `SKILL.md`。

## §0 两个机制（解释所有「为什么不听话」）

四格判据（有描述 / 有样本 / 有指令怎么选）只在 `SKILL.md` 模式表里写一次，这里不重复。一句话记：**克隆 = 参考音频自己会怎么念；导演 = 参考音频自己会怎么念 + 你要它改的地方。**

还有一条**和四格无关**的轴：参考文稿谁来给（内置 Whisper 自动转 / `--ref-text` 手写）。它不改「克隆还是导演」，只改音文对齐准不准，见 `模式详解.md` §一。

两个机制值得知道：

- **克隆的 cfg_scale = 1.0**：只跑一条路，没有反向拉力，模型干的事是"接着这段录音往下说"。所以语速、气息、音量、口音、连麦克风质感都跟着样本走，你想改都改不动。想偷一点语气变化，把 `--cfg` 往上调到 1.2–1.5。
- **导演是两条路相减**：`输出 = B + 4 ×（A − B）`，A 带指令、B 不带。相减时"是这个人"被抵消（但已留在基底），"这一刻的语速情绪"被放大 4 倍。**指令没提到的维度，A、B 里一模一样，抵消不掉，照样漏过来。**

## §1 音色描述（design）：四层公式

| 层 | 写什么 | 例 |
|---|---|---|
| ① 谁在说 | 性别 + 年龄 | 三十二岁男声 |
| ② 长什么样 | 高低 / 厚薄 / 质感 / 共鸣 | 音色偏中低，干净不带沙 |
| ③ 怎么演 | 语速 / 停顿 / 尾音 / 情绪 | 语速偏慢，尾音往下收 |
| ④ 像什么 | 场景或比喻 | 像在屋里压低嗓子跟人商量事情 |

**铁律：写物理特征和动作，不写形容词判断。**

| 别写 | 改写成 |
|---|---|
| 阴险的声音 | 笑意只停在嘴上，不到眼睛里；句尾轻轻往外送 |
| 好听的女声 | 二十六岁女声，音色偏亮但不尖，气声多，语速中等 |
| 霸总音 | 三十四岁男声，胸腔共鸣重，字咬得短，尾音一律往下压 |

**微调只改一个维度**（年龄 / 音色 / 语速 / 尾音里挑一处）。改三处等于重抽一次，钱花了还不知道是哪句起的作用。

**现成配方**：`references/声线库.md`，31 条实测过的描述 + 对应台词 + 实测字/秒，整段复制换台词即可。

## §2 导演指令：六维写密法

**为什么必须写密**：见 §0 导演的减法——没写到的维度抵消不掉。口音、鼻音、习惯性停顿、句尾上扬，不点名就照抄参考。

六个维度，缺哪个就漏哪个：

| 维度 | 写法示例 |
|---|---|
| 语速 | 比参考慢三成 / 快一倍 / 前两句慢、最后一句加快 |
| 音量 | 整体压低到耳边私语 / 后半段提起来逼近质问 |
| 情绪 | 冷淡克制、带一点疲惫的狠意 / 惊慌但强装镇定 |
| 气息 | 气声多、换气明显 / 一口气念完不换气 |
| 口音 | 普通话标准不带口音 / 保留轻微北方口音 / 港台腔 |
| 停顿 | 每句结尾停半拍 / 破折号处停一秒 / 不许停顿一口气冲完 |

坏例子 → 好例子：

```
坏：说得伤心一点
好：语速放慢到七成，音量压低，句尾下沉带气声，情绪克制不哭出来，
    每句结尾停半拍，普通话标准不带口音。
```

**指令的语言跟着台词语言走。** 中文台词配英文指令，指令遵循会明显变差。（官方原话：Match the instruction language to the target text。）

**一次只改一个维度做对照**：上一版「慢」这版加「冷」，别同时换三样——中了也不知道为什么中。

## §2.5 口音这一维（方言 / 地域腔）

「像广东人说话」写不出东西，模型只会照抄参考音频的口音。管用的是**具体音变**，下面六件事写全，缺一件就漏一件：

| 音变 | 写法 |
|---|---|
| 卷舌 | 没有卷舌音，是读 si、知读 zi |
| n / l | n 和 l 不分，你读里、年读连 |
| f / h | f 和 h 不分，风读 hong、湖读扶 |
| 尖团 | 保留尖团音，小读 siao、心读 sin |
| 入声 | 一、白、出 收得短促，一顿就断，不拖 |
| 句尾走向 | 句尾一律下沉 / 上扬拖长 / 往下飘带拖腔 |

这批十个方言（粤、川、东北、沪、陕、豫、湘、闽、鲁、津）实测有效，同一条指令里这六项以外再叠语速／音量／情绪／气息／停顿，十条全部一次过。

两条铁律：

1. **台词不写生僻方言字。** 嘅／喺／咗／嫑／嘞 直接进文本，会被按普通话读音念，出来是错音，不是方言。只用**常用字写的方言词**（咱、啥、瞅、甭、莫、俺、恁、您了），方言感交给指令。
2. **输出语言跟参考音频走。** 参考是普通话，产物就是「方言腔普通话」，不是纯粤语／纯闽南语。要纯方言，先换一段该方言的参考音频。

判断指令有没有吃进去：字/秒反查——口径与实测值见 `实测数据.md` §二。

## §3 语气事件

`[笑]` `[叹气]` `[咳嗽]` `[清嗓子]` 直接写进台词（中文方括号 / 英文圆括号，括号内不朗读、两三个够）。词表、括号配对的坑、实测数据与验证口径只在 `模式详解.md` §三 写一份，这里不重复。

## §4 参数只记两条

参数语义只在 `故障排查.md` §一 的全表里写一份；写作时真正相关的只有两条：`--cfg` 克隆 1.0 / 导演 4，产物 24kHz 单声道 flac（要 mp3 加 `--mp3`）。台词一条命令只提交一次：**单段超 150 字就该拆**（后半段语调会飘，音频仍完整）；要保证**念完整**，稳妥线是 design 600 字 / 带参考 400 字，≈660 字实测必吞——两条线不是一回事，阈值与核对办法见 `实测数据.md` §九。

## §5 三种模式怎么配合

| 情形 | 做法 |
|---|---|
| 一个角色要念一整章 | 先 `design` 定一条 10–20s 的"试音"，满意后拿它当 `--ref` 走 `clone` 批量念正文——音色锁死，后面每段都一致 |
| 同一角色要不同情绪 | 固定同一个 `--ref`，用 `director` 换指令。**别换参考音频**，换了人就不是同一个了 |
| 参考音频自带强烈情绪、去不掉 | 走 `director`，指令把语速/音量/情绪/气息逐条写反方向，比在 `clone` 里硬掰有效 |
| 多角色对白（2–4 人） | 走 `dialogue4`，一次出整段（cast.json 用法见 `模式详解.md` §五）。**别再用「逐句分次生成再拼」** |
