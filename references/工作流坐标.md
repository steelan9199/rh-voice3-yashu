```bash
node scripts/rhv.mjs wf all            # 全部 7 条：节点表 + 坐标核对 OK/BAD

```

## 改接线的四条雷区

1. **同一个节点号在不同图里不是一回事。** `#62` 在 clone·带文稿 是**参考文稿**，在 director 两张里是**导演指令**。改之前先 `node scripts/rhv.mjs wf <模式>` 看清是哪张图，别凭号改。
2. **输出节点别动。** `#39` 是第三方 `SaveAudioAdvanced`，把 `format` 改成 mp3 后任务照样 SUCCESS 但 `results` 返回空——钱花了音频没了。要 mp3 用 `--mp3` 本地转。`stt` 那边同理，别动 `#65 SaveText` 的 `format`。
3. **自动转写开关必须 false。** 图上四槽已置 `false`，脚本另恒推 `false` 兜底——为什么要两道、以及崩成什么样，见 `故障排查.md` §三。
4. **参考音频槽位只认上传接口返回的 `fileName`**（`openapi/xxx.flac`），不认本地路径、也不认下载 URL——上传与缓存机制见 `模式详解.md` §一。
